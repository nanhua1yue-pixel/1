# 采购补货决策系统

配套《采购主管月度绩效考核表》+《采购主管提成方案》的管理系统。

## 系统架构

```
backend/
  ├── app.py                    # Flask应用主入口
  ├── config/settings.py        # 配置(数据库/旺店通API/考核规则/提成方案)
  ├── models/
  │   ├── database.py           # 数据库连接
  │   ├── slow_moving.py        # 滞销品模型(SKU/日志/月度统计)
  │   ├── kpi.py                # 绩效考核+提成模型
  │   └── inventory.py          # 库存/SKU/采购订单模型
  ├── services/
  │   ├── slow_moving_service.py  # 滞销品处理服务
  │   └── kpi_service.py          # KPI评分+提成计算引擎
  ├── api/
  │   ├── slow_moving_api.py    # 滞销品API
  │   └── kpi_api.py            # KPI/提成API
  └── utils/
      └── wdt_client.py         # 旺店通API客户端

frontend/
  ├── index.html                # 主页面(Vue3 + Element Plus)
  ├── css/style.css             # 样式
  └── js/app.js                 # 前端逻辑

scripts/
  ├── init_db.sql               # 数据库初始化
  ├── deploy.sh                 # 宝塔面板部署脚本
  └── sync_data.py              # 旺店通数据同步(定时任务)
```

## 核心功能

### 1. 滞销品处理模块 (直接影响考核35分+提成700元)
- 滞销品列表(月销<10的SKU)
- 逐个/批量标记: "能退/不能退" + 处置动作
- 处理进度仪表盘(实时完成率)
- 全程操作日志可追溯
- 自动计算考核得分和提成金额

### 2. KPI评分引擎 (100分制)
- 六大维度自动评分
- 加分项/扣分项(铁律)
- 评分标准完全对应考核表

### 3. 提成计算
- 总提成 = (A.执行质量 + B.库存健康) × C.过程系数 - D.重大扣罚
- 三道锁防止"盲目压价拿低价"

### 4. 数据同步
- 对接旺店通API自动拉取库存/销售数据
- 自动识别滞销品
- 每日库存快照

## 考核绩效关系

| 系统模块 | 考核维度 | 分值 | 提成影响 |
|---------|---------|------|---------|
| 滞销品处理完成率 | 二、滞销管理 | 10分 | 700元 + ×1.1系数 |
| 滞销品处理完成率<60% | 铁律扣分 | -10分 | - |

| 库存周转数据 | 一、库存周转 | 30分 | 2000元 |
| 缺货SKU监控 | 四、缺货管控 | 12分 | - |
